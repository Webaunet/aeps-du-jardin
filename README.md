# Allibert Paysage — maquette

Maquette de site vitrine pour **Allibert Paysage**, paysagiste à Versailles (SIREN 833 518 467).

Pages : `index.html`, `nos-prestations.html`, `nos-realisations.html`, `a-propos.html`, `nous-contacter.html`, `mentions-legales.html`.

Les pages sont générées par `python3 outils/build.py` (corps dans `outils/pages/`). Images optimisées par `outils/images.py`.
